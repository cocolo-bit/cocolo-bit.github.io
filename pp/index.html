プライバシーポリシー

合同会社ココロビット（以下「当社」）は、当社が提供するスマートフォンアプリおよび本ウェブサイト（以下「本サービス」）における利用者情報の取扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」）を定めます。

第1条（取得する情報）

当社は、本サービスの提供にあたり、次の情報を取得することがあります。本サービスには会員登録機能はなく、氏名・住所・電話番号などの個人を直接特定する情報をアプリ上で入力していただくことはありません。

  1. 端末情報（OS の種類・バージョン、端末の機種、言語設定など）
  2. 広告識別子（iOS の IDFA、Android の広告 ID）
  3. アプリの利用状況（起動回数、プレイ状況、操作履歴など）
  4. クラッシュや不具合発生時の動作ログ
  5. IP アドレスおよびおおまかな地域情報
  6. お問い合わせの際にご提供いただくメールアドレスおよびお問い合わせ内容

第2条（利用目的）

当社は、取得した情報を次の目的で利用します。

  1. 本サービスの提供・運営のため
  2. 本サービスの改善および新サービスの検討のための利用状況の分析
  3. 不具合の調査・修正のため
  4. 広告の配信（利用者の興味・関心に応じた広告を含む）および広告効果の測定のため
  5. お問い合わせへの対応のため

第3条（外部サービスの利用）

本サービスでは、次の外部サービスを利用しています。これらのサービスにより、第1条の情報の一部が各事業者に送信され、各事業者のプライバシーポリシーに基づいて取り扱われます。

Google AdMob（Google LLC）
広告の配信に利用しています。広告識別子、端末情報、IP アドレスなどが送信されます。
Google のサービスを使用するサイトやアプリから収集した情報の Google による使用
Firebase（Google LLC）
Google Analytics for Firebase による利用状況の分析、および Firebase Crashlytics による不具合の解析に利用しています。端末情報、利用状況、クラッシュログ、アプリ単位の識別子などが送信されます。
Firebase のプライバシーとセキュリティ

Google のプライバシーポリシーは こちら をご確認ください。

第4条（広告のパーソナライズの停止）

利用者は、端末の設定により、興味・関心に基づく広告の表示や広告識別子の利用を制限できます。

  • iOS：「設定」>「プライバシーとセキュリティ」>「トラッキング」で、アプリからのトラッキング要求を許可しないよう設定できます。
  • Android：「設定」>「Google」>「広告」から、広告 ID の削除やリセットができます。

第5条（第三者提供）

当社は、第3条に定める外部サービスへの送信を除き、次の場合を除いて、あらかじめ利用者の同意を得ることなく個人情報を第三者に提供しません。

  1. 法令に基づく場合
  2. 人の生命、身体または財産の保護のために必要がある場合であって、本人の同意を得ることが困難であるとき
  3. 国の機関もしくは地方公共団体またはその委託を受けた者が法令の定める事務を遂行することに対して協力する必要がある場合
  4. 合併その他の事由による事業の承継に伴って提供される場合

第6条（開示・訂正・削除等の請求）

当社が保有する利用者ご本人の個人情報について、開示・訂正・利用停止・削除のご請求があった場合は、ご本人であることを確認のうえ、法令に従い遅滞なく対応します。ご請求は第8条の窓口までご連絡ください。なお、第3条の外部サービスが取得した情報については、各事業者の定める方法に従ってください。

第7条（本ポリシーの変更）

当社は、必要に応じて本ポリシーを変更することがあります。変更後の本ポリシーは、本ページに掲載した時点から効力を生じるものとします。
