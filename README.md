# cocolo-bit.github.io

合同会社ココロビットのコーポレートサイトとプライバシーポリシー。GitHub Pages で公開する。

- 公開 URL: https://cocolobit.com/ （DNS 切り替え前は https://cocolo-bit.github.io/ ）
- プライバシーポリシー: `pp/index.html`

## 注意

- **`pp/index.html` のパスは変えないこと。** App Store / Google Play に `https://cocolobit.com/pp/index.html` として登録している。
- このリポジトリは Public。秘密情報を置かないこと。
- 独自ドメインは `CNAME` ファイルで設定する。
